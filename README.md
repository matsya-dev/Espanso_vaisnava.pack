\\\\\\ ESPANSO TRIGGER SYSTEM ///



This system converts common Sanskrit terms and expands verses/translations into plain text (ASCII), Unicode (IAST), and Balaram (Legacy) encoding.


English auto-correct (to fix common spelling mistakes) and auto-contraction (to automatically add apostrophes in contractions) packages are also included. 

\[to disable, delete these from the "packages" folder]





\\\\\\ HOW TO TYPE A TRIGGER ///

Type the trigger exactly as shown, with no spaces, and finish it with the desired suffix.



Suffixes:

: = plain text

> = Unicode IAST
< = Balaram



Example:

Type:

SP:

Espanso changes it to:

Srila Prabhupada



Type:

SP>

Espanso changes it to:

Śrīla Prabhupāda



Type:

SP<

Espanso changes it to:

Çréla Prabhupäda



For Sanskrit words, type the plain spelling followed immediately by a suffix (> or <).

Example:

krsna> = Kṛṣṇa
krsna< = Kåñëa

sloka> = śloka
sloka< = çloka



\\\\\\ VERSES/TRANSLATIONS ///



To insert a verse, type the reference abbreviation followed by the verse number and desired suffix.



REFERENCE ABBREVIATIONS:

BG       = Bhagavad-Gita
SB       = Srimad-Bhagavatam
CC       = Sri Caitanya-Caritamrta
CB       = Sri Caitanya-Bhagavata
NOI      = Nectar of Instruction
ISO      = Sri Isopanisad
ISOINV   = Sri Isopanisad Invocation
BS       = Sri Brahma-Samhita



VERSE NUMBERS:

The verse number must be typed right after the reference abbreviation without any spaces.

Format: \[Canto/Lila/Khanda#].\[Chapter#].\[Verse#]

For Sri Caitanya-Caritamrta/Bhagavata:

Adi = 1

Madhya = 2

Antya = 3



Examples:

BG1.1> = Bhagavad-Gita 1.1 verse in Unicode
SB1.1.1< = Srimad-Bhagavatam 1.1.1 verse in Balaram
CC1.1.1: = Sri Caitanya-Caritamrta Adi-Lila 1.1 verse in plain text



TRANSLATIONS:

To insert a translation, type T immediately after the verse number and before the suffix.



Examples:

BG1.1T> = translation in Unicode
BG1.1T< = translation in Balaram
BG1.1T: = translation in plain text
